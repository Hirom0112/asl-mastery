## How to fill this in

The full T5 procedure is:

```bash
# Source the Modal env once per shell.
source training/.venv/bin/activate

# 0. Authenticate Modal (one-time per machine).
modal token new

# 1. Push the cleaned dataset (already on disk from Phase 3f /
#    training/data/clean.py) to the Modal Volume.
modal volume create asl-mastery-data       # idempotent
modal volume put asl-mastery-data dataset/clean/v3 /datasets/v3

# 2. Smoke-train on 1–2 signs first to verify the pipeline runs
#    end-to-end before committing to the full vocabulary.
#    (Create a tiny manifest with two signs' clips first; details
#    below in the smoke-test section.)
modal run training/modal_app.py::train \
    --manifest /datasets/v3/dataset_v3_smoke_manifest.json \
    --run-id v3-smoke \
    --epochs 5

# 3. Full training on the 75-sign vocabulary.
modal run training/modal_app.py::train \
    --manifest /datasets/v3/dataset_v3_manifest.json \
    --run-id v3-001 \
    --epochs 60

# 4. Validate on the held-out test split.
modal run training/modal_app.py::validate \
    --manifest /datasets/v3/dataset_v3_manifest.json \
    --run-id v3-001

# 5. Export INT8-quantized ONNX artifact bundle.
modal run training/modal_app.py::export \
    --run-id v3-001 \
    --artifact-version v3.0.0

# 6. Pull artifacts back to the laptop.
modal volume get asl-mastery-data /runs/v3-001 ./runs/v3-001
modal volume get asl-mastery-data /artifacts/v3.0.0 ./artifacts/v3.0.0

# 7. Run the eval-gate enforcer locally on the report.
python scripts/check_eval_gate.py runs/v3-001/validation.json

# 8a. IF the gate passes (top-1 ≥ 85%, all per-sign ≥ 60%, etc.):
#     - Upload the ONNX bundle to R2:
#         wrangler r2 object put asl-mastery-models/v3.0.0/classifier.onnx \
#             --file artifacts/v3.0.0/classifier.onnx
#         wrangler r2 object put asl-mastery-models/v3.0.0/config.json \
#             --file artifacts/v3.0.0/config.json
#     - Add a model_versions row in Supabase + flip is_active:
#         (write a migration like
#          supabase/migrations/20260521000000_promote_v3_0_0.sql)
#     - Promote: the practice screen will drop the offline banner on
#       next page load.
#     - Replace this entire file with the full report (numbers,
#       per-sign accuracy, confusion analysis, etc.).
#
# 8b. IF the gate fails (the honest expected outcome under Path B
#     with our data scale): write the honest report below naming the
#     gap, do NOT promote, and either iterate or escalate scope-relief
#     to the user.
```

The handoff names the honest expected outcome explicitly: **30–50 %
top-1 accuracy on 75 signs**, below the 85 % floor. ADR 0001 sized
Path B for ~200 clips/sign; the merged WLASL + ASL Citizen + Sem-Lex
corpus gives ~30–90 clips/sign. If iteration genuinely stalls below
50 % top-1 on more than a handful of signs in T5, surface a
scope-relief ask (smaller vocab, lower floor, or commit to the
ADR 0004 instructor engagement) before throwing more iterations at it.

## Architecture under evaluation

- **Model:** `SmallR2Plus1D` (`training/classifier/cnn.py`)
  - R(2+1)D-style factored 3D conv (1×3×3 spatial composed with
    3×1×1 temporal) per Tran et al. 2018.
  - Stem + 4 res-stages with channel ladder [64, 128, 256, 512].
  - Global spatiotemporal average pool → linear classifier head.
  - ~7.5 M parameters at T=16, H=W=96 (inside the 5–10 M target
    from `docs/MODEL.md` §1).
  - Kaiming-normal initialization everywhere; biases zero; BN scale 1.
    **No `load_state_dict` call. No external classifier weight URL.
    No pretrained backbone.** Audit surface = `training/classifier/cnn.py`.
- **Input:** raw RGB video tensor `(B, T=16, H, W, 3)` float32 in
  [0, 1]. Channel-last from the browser; the model permutes to
  `(B, 3, T, H, W)` for Conv3d internally and the permute carries
  through to ONNX export so the wire format stays simple.
- **Training:** AdamW (lr 1e-3, wd 1e-4), cosine annealing across the
  full run, label smoothing 0.1, weighted sampler for class balance,
  batch 32, mixed precision (AMP), gradient clip 1.0, 60 epochs max
  with early stopping patience 8.
- **Augmentation (pixel-level, per ADR 0005 — load-bearing again
  under ADR 0010):** random spatial crop, color jitter
  (HSV brightness/contrast/saturation), MOG2 background swap
  (classical CV), small affine (≤±10°, ≤±5% scale, ≤±3% translate),
  conditional horizontal flip (only on `flippable: true` signs).
- **Calibration:** temperature scaling on validation; per-sign
  confidence thresholds tuned for ≥90% precision on the "pass"
  decision.
- **Export:** PyTorch → float32 ONNX → INT8 dynamic quantization
  (required under Path B per `docs/MODEL.md` §6 to stay within the
  ≤10 MB bundle target). Float32 parity check at export; eval-gate
  re-validation on the quantized model on real test set is required
  before promotion.
