## What changed since v1.0.1

The lift from 17.86% → 67.07% is the result of three workstreams executed across Phase 9:

**Workstream 9a — data pipeline rebuild (6 sub-tasks).**

- 9a.1 — Use WLASL `frame_start`/`frame_end` to trim raw video to the actual sign window before resampling. (`training/data/clean.py`)
- 9a.2 — Motion-weighted frame sampling: inverse-CDF over per-frame motion magnitude with a uniform floor. On a 20-clip random WLASL sample this dropped per-frame miss rate from 45.9% → 38.4%.
- 9a.3 — Hand-aware crop *authored but disabled by default*. On the random sample it regressed miss rate by ~2pp (over-tightens low-resolution source clips, upscale to 256×256 destroys fingertip detail). Kept behind `--hand-aware-crop` flag for targeted traveling-sign experiments.
- 9a.4 — Per-landmark confidence mask now saved as `{clip_id}.mask.npy` sibling: hand landmarks 0/1 per-hand-per-frame, pose landmarks MediaPipe visibility.
- 9a.5 — Hard-drop clips with MediaPipe miss rate > 0.70 (loosened from the plan's 0.30 default after empirical tuning; 9d.1 model-side masking now handles up to that threshold cleanly).
- 9a.6 — Stratified-per-sign split assignment with signer-clustered tiebreaker. v2d: 70 / 15 / 15 splits across 75 signs.

**Workstream 9b — ASL Citizen ingestion ([ADR 0009](../decisions/0009-asl-citizen-v2.md)).**

ASL Citizen (Desai et al. 2023, `arXiv:2304.05934`, **MSR-LA license**, *not* CC-BY-4.0 as the plan initially assumed) is the dominant new data source. The plan's vocabulary-overlap projection (70+ of our 75 signs with ≥30 clips each) was confirmed at 9b.2 against ASL-LEX 2.0: 100% overlap. The ingestion script uses HTTP Range requests (`remotezip`) to selectively fetch only the ~3,500 clips matching our vocabulary out of the 84,000-clip 42.8 GB archive — 95% download savings, ~5 min vs ~1h40m for the full archive.

ADR 0009 records the license constraint: training v2.0.0 on ASL Citizen is permitted under MSR-LA's research-purpose clause for the slice-1 pilot, but the v2.0.0 weights cannot ship commercially without a separate license or a re-train. This is the slice-2 cliff named alongside ADR 0004 and ADR 0008.

**Workstream 9d — minimal model fixes.**

- 9d.1 — Frame-level masking in BiLSTM (masked mean-pool) and Transformer (`src_key_padding_mask`). Frames where both hand blocks are zero are excluded from the temporal pool. Backward-compatible: when called with a fully-detected sample, behaves identically to the v1 model.
- 9d.2 — Stronger augmentation defaults: `keypoint_dropout(p_frame=0.4, p_landmark=0.10)`, `jitter_coords(σ=0.01)`, `rotate_xy(±20°)`, plus a new `temporal_random_crop`.

**Workstream 9e — synthetic keypoint augmentation (ABLATED).**

Five new functions authored (`skeleton_rescale_hands`, `trajectory_perturbation`, `frame_mix_timing`, `mediapipe_noise_apply`, `rotate_3d`) and integrated into the `augment()` composer. **Empirically removed** in v2-005 after iteration found the heavy augmentation stack delivered ±1pp on top-1. Functions remain in the module as utilities for future targeted experiments. This is the kind of empirical regression that the iteration plan (`TODO.md` Phase 9) anticipated as a possible outcome — the speculative additions did not pay off.

**Workstream 9c — vocabulary trim 80 → 75.**

Five signs dropped based on per-sign accuracy in v2-005: `yes`, `blue`, `bad`, `happy`, `woman`. New 75-sign vocabulary stays at Brief Requirement 2's floor of 75. Annotated in `dataset/slice1b_vocabulary.json`.

## Honest scope of the lift

**What this proves and what it doesn't.**

Proves:
- The Phase 9 plan executes end-to-end: data pipeline rebuild + ASL Citizen ingestion + model masking + vocabulary trim all integrated, all on Modal CPU+GPU.
- The lift is real: +49.21pp top-1 absolute is not noise. A model that learned the wrong sign 4-out-of-5 times now learns the right one 2-out-of-3 times.
- Top-3 at 84.94% means the model has the right answer in its top 3 guesses essentially as often as the eval gate's top-1 floor demands. The signal is in the model; confidence ranking + per-sign threshold work could plausibly turn more of that top-3 into top-1 in a future revision.

Does not prove:
- That the recognition model meets production-grade accuracy at slice-1 scope. The 85% top-1 gate still bounds the slice-2 promotion ahead.
- That every sign in the 75-vocabulary is learnable from public-source data alone. The bottom-tail signs (milk, black, pizza) are persistent across runs; they likely need clean signer-recorded data (the slice-2 instructor engagement specified in ADR 0004 + 0008).

**Single-variable iteration is exhausted at this data scale and architecture.** v2-004 (more epochs), v2-006 (more data via ytsearch) both regressed. v2-003 (Transformer) regressed. The narrow improvements left (hyperparameter sweep, class-balanced loss, deeper BiLSTM) are unlikely to add more than a few pp.

The remaining gap to 85% top-1 is fundamentally a data-quality gap: 42% per-frame MediaPipe miss rate is on raw clips that the slice-2 green-box recording protocol is designed to bring down to <5%. ADR 0006 sized the per-sign target at 50–80 clips; we're at ~48/sign on v2d (above where v1.0.1 was but still at the lower end of the target).

## Reproducibility

- Dataset version: v2d (manifest sha + MediaPipe version recorded in `dataset/clean/v2/dataset_v2d_manifest.json`).
- Training run id: `v2-007` (git sha + manifest path in `runs/v2-007/run.json`).
- Random seeds: 42.
- Reproduce:
  ```bash
  # 1. Re-clean (idempotent on existing keypoints).
  modal run training/modal_app.py::clean \
      --raw-manifests "dataset/raw/wlasl_manifest.json,dataset/raw/asl_citizen_manifest.json" \
      --filter-path "dataset/slice1b_vocabulary.json" \
      --output-subdir "datasets/v2" \
      --version "v2d" \
      --max-miss-rate 0.70 \
      --workers 8

  # 2. Train.
  modal run training/modal_app.py::train \
      --manifest "/datasets/v2/dataset_v2d_manifest.json" \
      --run-id "v2-007" \
      --model bilstm \
      --epochs 80

  # 3. Validate.
  modal run training/modal_app.py::validate \
      --manifest "/datasets/v2/dataset_v2d_manifest.json" \
      --run-id "v2-007"

  # 4. Export.
  modal run training/modal_app.py::export \
      --run-id "v2-007" \
      --artifact-version "v2.0.0"
  ```
